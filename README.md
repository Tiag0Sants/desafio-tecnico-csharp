# Meu desafio técnico em C#

Fiz este projeto para resolver o desafio técnico usando C#. Ainda estou aprendendo a linguagem, então aproveitei o exercício para praticar lógica, leitura de JSON, listas e classes.

## O que o programa faz

- Lê as vendas e calcula a comissão de cada uma.
- Lê os produtos e permite registrar entradas e saídas do estoque.
- Informa o saldo atualizado depois de cada movimentação.
- Calcula os juros de atraso com base no valor e na data de vencimento.

## Como executar

1. Abra a solução no Visual Studio.
2. Execute com **F5**.
3. Informe os dados solicitados no terminal.

Para o cálculo de juros, considerei uma taxa simples de 2,5% por dia de atraso.
